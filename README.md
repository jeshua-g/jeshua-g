## Open source

**KeyStroke**, a low-latency on-screen keystroke overlay for tutorials and
streaming. Multi-line layout, modifier combos, MechVibes sound packs, and a
display-only UI that passes mouse input through to the app underneath.

- Linux: GNOME Shell extension on Wayland, using an AT-SPI keyboard monitor, GStreamer audio, and GSettings preferences.
- Windows: native Rust and Win32 port using `WH_KEYBOARD_LL` and a layered click-through overlay. No Electron, with cross-platform key logic under unit test.
